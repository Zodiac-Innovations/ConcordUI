# ConcordUI

<https://github.com/Zodiac-Innovations/ConcordUI>

Shared Swift UI framework and native Apple renderer for ConcordUI applications.

The `ConcordUI` library contains the platform-independent application, presentation, venue, element, feature, and platform service APIs. Shared application code imports `ConcordUI` on Apple and Android. The `ConcordUIApple` library provides the native Apple host and rendering implementation.

Android applications use the shared `ConcordUI` library together with the Android bridge and Kotlin host generated by the ConcordUI command-line tool in each application project. The app-specific bridge is not a separate product in this package.

## Swift Package Manager

Add this repository as a package dependency in Xcode or in a Swift package:

```swift
.package(url: "https://github.com/Zodiac-Innovations/ConcordUI.git", branch: "main")
```

Depend on `ConcordUI` for shared application code. Apple hosts also depend on `ConcordUIApple`. This repository contains the package sources and Core tests; complete applications and screenshots are in [ConcordUIExamples](https://github.com/Zodiac-Innovations/ConcordUIExamples).

## Source layout

- `Sources/ConcordUI` — shared Core APIs used by Apple and Android applications.
- `Sources/ConcordUIApple` — Apple platform host, renderer, and resource.
- `Tests/ConcordUITests` — Core unit tests.

## Android project generator

`Tools/AndroidGenerator` contains the Android glue and project-generation code. `concordui android create` clones the `repo` and `branch` recorded in `ConcordUI.info`, runs this Swift package, and generates the project's `Android/` folder and Swift package manifest. Android glue changes can therefore be published in this repository without rebuilding the ConcordUI CLI. The developer needs Git, a host Swift toolchain, Gradle, and Android tooling; the generator compiles locally when invoked. Use `concordui android create -d` to replace an existing generated Android project after updating this repository. Back up project-specific edits inside `Android/` before regenerating.

The generated application's `Package.swift` also points to the selected `repo` and `branch`. An experiment repository must include both the ConcordUI Swift products and `Tools/AndroidGenerator`.
